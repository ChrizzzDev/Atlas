# Contributing to Atlas

Thanks for your interest in contributing to Atlas.

## Development

1. Clone the repository
2. Install V
3. Run `v run . /path/to/project`

## Before submitting a PR

- Format your code with `v fmt`
- Make sure tests pass
- Keep changes focused
- Add tests for new behavior when appropriate

## Commit messages

Use clear and descriptive commit messages.

Examples:

scanner: ignore generated directories
output: improve language statistics
test: add unreadable file case
